# 🧮 Average Marks Calculator

A small Python desktop app (Tkinter) that calculates a student's internal marks from two mid-term exams and an assignment.

## ✨ Features

- Input boxes for **Mid 1**, **Mid 2** and **Assignment** marks
- Calculates: `(Mid 1 + Mid 2) / 2 + Assignment`
- Shows the result in the app window (each calculation is appended)
- Handles invalid input (non-numbers) with a message in the console

## 🛠️ Tech Stack

- Python 3
- Tkinter (standard-library GUI)

## 📁 Project Structure

```
average-marks-calculator/
└── avg_cal.py   # The complete Tkinter app
```

## 🚀 Run Locally

Tkinter ships with most Python installs – no extra packages needed.

```bash
git clone https://github.com/shivamani-code/average-marks-calculator.git
cd average-marks-calculator
python avg_cal.py
```

Enter the marks as whole numbers and click **Get Text** to see the result.
